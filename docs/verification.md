# Verification · MVP / local pilot

All test accounts, cases, cost receipts, subscriptions and screenshots are fictional. Nothing deployed, provisioned, merged, sent to a buyer or submitted to a carrier. No real mail or paid LLM call was performed.

- Strict TypeScript and ESLint pass for app, shared engine/MCP and all backend modules. Bindings are generated by Wrangler.
- Vitest: 83 tests across 10 files. Existing WC/GL math, no-AI, BYOK, registration and real MCP transport/OAuth tests remain. Added CSV import validation, workflow/report safety, legacy JSON defaults, tenant isolation and revocation, paginated teammates beyond 100, stale-write rejection, account deletion protection, atomic 50 GB gating, paid allowance/expiry behavior, suspension, private document download, admin authorization/logging, recorded costs at 2×, duplicate cost protection and consent-aware learning/export suppression.
- Offline benchmark tests compare independent numeric references, withheld results, candidate-category misses/extras, human-review unknowns, separate synthetic/real-labelled fixture cohorts and timing. Actual CLI subprocess tests write only to temporary private folders, reject repository paths and junctions, and prevent overwrites. All fixtures remain synthetic; no real client accuracy has been measured.
- Checked-learning tests cover source-quote validation, verification reset, immutable original drafts, approved/scope-only context, owner-only approval, revision conflicts, withdrawal, cross-tenant denial and immutable original/corrected snapshots with exact lesson versions. A separate synthetic mocked-model browser test feeds an audit, records a staff correction, approves it and verifies the next request receives the approved lesson. This proves plumbing, not actual client/provider improvement.
- Main browser workflow verifies signup, optional choices off, both audit modes, local PDF text, keyboard focus, evidence indexing, request/Markdown/printable HTML downloads, saved tenant case recovery, JSON import/export, no-AI and mobile layout.
- Additional real browser contexts verify tenant owner, teammate, outsider and allowlisted Sourcy admin; switching/isolation, document download, shared edits and visible conflicts, owner-only controls, revocation, persisted cost quote and restricted export. All use a loopback test server and fictional identity.
- Tested axe WCAG 2.1 A/AA states have zero reported violations. No observed browser runtime errors. The primary workflow observes no unexpected external requests. These focused checks are not comprehensive accessibility certification or a penetration test.
- App build and Worker dry-run bundle pass. CI additionally runs isolated browser verification with Chromium. No real deployment is part of CI.
