# GL: the class tells you which exposure to measure

General liability is a separate rating system. Do not carry WC payroll exclusions, officer caps, experience mods or subcontractor decisions into GL without independent policy authority.

For each class, record its description, rating basis, rate denominator and rate from the policy schedule. The app supports payroll, gross sales, subcontract cost and units. These are input types, not a universal ISO class table. Carrier deviations, endorsements and different operations can change the answer.

| Basis | Reconciliation | Common question |
| --- | --- | --- |
| Payroll | Payroll register → policy-period class exposure | Which compensation items belong in this class basis? |
| Gross sales | Sales ledger / P&L → policy-period class exposure | Which sales exclusions are actually allowed? |
| Subcontract cost | Contracts and payment ledger → chargeable costs | Are insured subs retained, excluded or rated separately? |
| Units | Source count → units specified by class schedule | Is the rate per unit, per thousand or another denominator? |

Every proposed excluded sale or cost should have an amount, ledger reference and rule authority. A deduction that reduces financial-statement revenue is not automatically a GL rating exclusion. Returns, taxes, freight, intercompany transactions or other categories require the applicable definition; this guide does not declare them universally excludable.

For sub-cost classes, separate insured and uninsured amounts. A COI proves information about insurance; it does not alone establish a full GL premium exclusion. When the policy rates insured subs separately, retain those costs on a separate row at the verified rate instead of subtracting them entirely. Avoid counting the same cost in more than one base.

Calculate each line as chargeable exposure / stated denominator × user-supplied rate. Then follow the policy’s premium element sequence and reconcile deposits. Show unknowns as TODO. The default denominator in a new GL row is an editable input convenience, **not a statement about the applicable class**; verification is required before a final estimate appears.

Obtain the policy-effective ISO Commercial Lines Manual GL classification and premium-basis rules through your carrier or licensed professional. [Verisk’s PAAS catalog](https://www.verisk.com/4a5f82/siteassets/media/downloads/iso/paas/paas-professional-development-catalog.pdf) provides background on premium-audit training; it is not a current rating manual. This project does not redistribute ISO content.

For disputes, start with the carrier. NCCI’s WC process is not a GL appeal channel. See [Dispute](dispute.md).
