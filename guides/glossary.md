# Plain-English glossary

| Term | Meaning in this workspace |
| --- | --- |
| Audit exposure | Actual payroll, sales, sub cost or units measured for the policy period |
| Class code | A rating classification whose applicability must be checked against operations and governing rules |
| Rate | The policy’s price per specified exposure unit; enter your own verified rate |
| Basis / denominator | What is measured and how many exposure units one rate applies to |
| Manual premium | Sum of class exposure × rate before the app’s subsequent rating elements |
| Experience mod | WC experience-rating factor with an effective period; not a generic GL adjustment |
| OT premium portion | The extra pay above straight-time for overtime work; not all overtime pay |
| Officer limit | Applicable minimum / maximum remuneration used under verified rules for an individual and period |
| COI | Certificate of insurance; verify issuer, entity, line and dates; not a substitute for the policy |
| DWC exemption | Florida individual exemption subject to eligibility and effective-date requirements |
| Minimum premium | A verified premium floor applied where the governing calculation requires |
| Expense constant | A policy premium element whose value and treatment must be verified |
| Assessment | A specified charge with a particular base, rate and effective rule |
| Deposit premium | Premium credited as already paid; reconcile against the payment ledger |
| Balance due | Final premium less credited deposit/payments, when positive |
| Return premium | Amount of overpayment indicated by a negative final-minus-deposit balance |
| Re-audit | Carrier review using corrected or additional records, subject to applicable requirements |
| Standalone impact | Difference caused by one proposed adjustment within a full scenario; may overlap other impacts |
| Verified | Reviewer checked the source, policy authority, entity, dates and applicability; not an automatic software certification |
| TODO | Unknown or unverified; never silently substituted with a factual figure |

Source register: [Florida](states/fl.md). See [WC](wc.md) and [GL](gl.md) for their different treatment.
